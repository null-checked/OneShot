# Test Generation Improvements

## Overview

Enhanced test file generation to ensure correct imports and proper test execution by improving code structure parsing and test command handling.

---

## Problems Solved

### 1. **Import Errors in Test Files**

**Previous Issue:**
```python
# arithmetic.py had:
class Arithmetic:
    @staticmethod
    def addition(a, b):
        return a + b

# test_arithmetic.py tried:
from arithmetic import addition, subtraction  # ❌ ImportError!
```

**Root Cause:** Test writer couldn't distinguish between class methods and standalone functions.

### 2. **Incorrect Test Commands**

**Previous Issue:**
```bash
# Architect generated:
python -m unittest tests/test_file.py  # ❌ unittest expects module paths!

# Error:
ModuleNotFoundError: No module named 'tests.test_file'
```

**Root Cause:** unittest requires module paths (dots), not file paths (slashes).

---

## Solutions Implemented

### 1. **Intelligent Code Structure Parsing**

Added `_parse_code_structure()` method to `dynamic_worker.py` that analyzes Python code to identify:

- **Classes and their methods**
- **Standalone functions**
- Proper import paths

#### Implementation:

```python
def _parse_code_structure(self, content: str) -> Dict[str, Any]:
    """
    Parse Python code to extract classes, methods, and standalone functions.

    Returns:
        {
            "classes": [{"name": "ClassName", "methods": ["method1", "method2"]}],
            "standalone_functions": ["func1", "func2"]
        }
    """
    # Analyzes indentation to detect class boundaries
    # Skips private/magic methods (starting with _)
    # Identifies function context (inside class vs standalone)
```

#### Example Output:

**For class-based code:**
```python
# Input:
class Arithmetic:
    @staticmethod
    def addition(a, b):
        return a + b

# Structure:
{
    "classes": [{"name": "Arithmetic", "methods": ["addition"]}],
    "standalone_functions": []
}
```

**For standalone functions:**
```python
# Input:
def add(a, b):
    return a + b

# Structure:
{
    "classes": [],
    "standalone_functions": ["add"]
}
```

### 2. **Enhanced Test Writer Context**

Test writers now receive detailed code structure information:

```
**CODE TO TEST** (already generated by other agents):

arithmetic.py (import as: arithmetic):
  Class: Arithmetic
    Methods: addition, subtraction, multiplication, division
    Import: from arithmetic import Arithmetic

calculator.py (import as: calculator):
  Standalone Functions: add, subtract, multiply, divide
  Import: from calculator import add, subtract, multiply, divide
```

#### Rules Provided to Test Writer:

```
**TEST GENERATION RULES**:
- ONLY test functions/classes that actually exist (listed above)
- Use the EXACT import statements shown above
- For class methods, import the class and use ClassName.method() or create instance
- For standalone functions, import them directly
- Create comprehensive test cases for each function/method
```

### 3. **Automatic Test Command Fixing**

Enhanced `testing_agent.py` to automatically fix malformed test commands:

#### Before:
```python
# Architect generates:
"python -m unittest tests/test_file.py"

# Error:
ModuleNotFoundError: No module named 'tests.test_file'
```

#### After:
```python
def _run_unit_test(self, project_path: Path, test_command: str):
    # Detect malformed unittest commands
    if "python -m unittest" in test_command and (".py" in test_command or "/" in test_command):
        # Auto-convert to pytest or discover mode
        test_command = "python -m pytest tests/ -v" if has_pytest else "python -m unittest discover -s tests -v"

    # Fallback retry with pytest if unittest module import fails
    if "ModuleNotFoundError: No module named 'tests." in result.stderr:
        alt_command = "python -m pytest tests/ -v"
        result = self.executor.execute_command(alt_command, str(project_path))
```

## Technical Details

### Files Modified:

1. **`src/core/dynamic_worker.py`**:
   - Added `_parse_code_structure()` method
   - Enhanced test writer context with structure information
   - Improved import guidance

2. **`src/core/testing_agent.py`**:
   - Added test command validation and fixing
   - Auto-conversion to pytest when unittest fails
   - Added `_has_pytest()` helper method

### Key Functions:

#### `_parse_code_structure(content: str)`
- **Purpose**: Parse Python code to extract structure
- **Returns**: Dict with classes (+ methods) and standalone functions
- **Features**:
  - Indentation-aware parsing
  - Skips private/magic methods
  - Handles mixed code (classes + functions)

#### `_run_unit_test(project_path: Path, test_command: str)`
- **Purpose**: Execute unit tests with command auto-fixing
- **Features**:
  - Detects malformed unittest commands
  - Auto-converts to pytest or discover mode
  - Fallback retry on import errors
  - Gracefully skips missing test files
